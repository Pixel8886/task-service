# Сервис задач

## Описание

Сервис задач предназначен для создания, просмотра, изменения и удаления задач.

## Основные возможности

- создание задачи;
- просмотр списка задач;
- изменение задачи;
- удаление задачи;
- изменение статуса задачи.

## Статусы задач

- Новая
- В работе
- Выполнена
